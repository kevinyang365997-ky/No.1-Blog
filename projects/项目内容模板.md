# 项目介绍

这里简要说明项目背景、目标和基本情况。

## 项目信息

- 项目类型：主导项目
- 项目时间：
- 项目地点：
- 项目状态：
- 承担角色：

## 项目背景

介绍项目为什么启动、当时面临的业务背景或实际需求。

## 客户或使用方需求

在不泄露隐私和商业信息的情况下，说明项目需要实现的目标。

例如：

- 达到目标产能
- 优化原有流程
- 提高工作效率
- 降低维护成本
- 改善操作体验

## 项目挑战

介绍项目实施过程中存在的问题和限制。

例如：

- 时间紧张
- 场地受限
- 资源有限
- 信息不完整
- 多方协作复杂
- 技术条件受限

## 我的角色

说明自己在项目中承担的角色。

例如：

- 项目负责人
- 方案负责人
- 技术支持
- 项目协调
- 内容与资料整理
- 团队成员

## 我的工作

具体说明自己完成了哪些工作：

1. 分析项目需求。
2. 制定实施计划。
3. 整理项目资料。
4. 协调项目参与方。
5. 跟进执行进度。
6. 处理实施问题。
7. 完成项目总结。

## 解决方案

说明采用的方案、方法和选择理由。

### 方案设计

介绍整体方案。

### 实施步骤

1. 项目准备
2. 需求确认
3. 方案制定
4. 实施执行
5. 测试验证
6. 结果交付
7. 项目复盘

## 使用的工具与资源

- 工具一
- 工具二
- 软件或平台
- 文档和资料
- 设备或系统

## 项目图片

图片准备好后，可以使用：

```markdown
![项目现场](/image/projects/project-template/project-site.jpg)
```

## 关联视频

视频库完成后，可以使用：

```text
@[video](video-id)
```

其中 `video-id` 是视频库中对应视频的唯一 ID。视频链接只在视频库中维护，项目页面通过 ID 自动关联。

## 文件附件

公开文件可以使用：

```markdown
[下载项目说明文件](/files/projects/project-template/project-document.pdf)
```

不得上传合同、报价、客户隐私、内部图纸、密码或未授权资料。

## 项目成果

说明最终取得的结果，例如：

- 完成项目交付
- 达到预定目标
- 改善工作流程
- 提高工作效率
- 降低运行成本
- 积累可复用经验
